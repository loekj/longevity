# Longevity Protocol

A standalone page to build, plan and track a personal longevity protocol: discovery tests, a 52-week plan of modules, marker goals, diet and a searchable treatment library.

Live page: https://loekj.github.io/longevity/

The data you enter stays in your own browser (localStorage). Use Export and Import in the page to back it up or to move it to another device.

The content is for information only and is not medical advice.
